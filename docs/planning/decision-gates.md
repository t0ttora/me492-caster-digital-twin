# Decision Gates and Access Contingencies

Dependencies that determine the permitted conclusions

| Gate | Evidence and decision |
| --- | --- |
| G1 16 Oct | Platform/software identified, allowed data exports and robot slots recorded. Pose-reference approach agreed. Otherwise freeze a provisional robot model and request the missing items with a due date. |
| G2 23 Oct | Stable nominal/caster simulations and one usable logging pilot. If CAD is unavailable, use measured simplified geometry and retain that limitation. |
| G3 6 Nov | Data route, independent pose and experiment access pass quality review. Without them, seek advisor agreement by 9 Nov for the reduced validation scope. |
| G4 20 Nov | Calibration complete enough to define a defensible comparison. Lock the finalist profile before the confirmation dataset. Simplify unidentifiable parameters. |
| G5 6 Dec | Model, input/target definition and test protocol frozen. If labels or independent runs are inadequate, deliver a feasibility analysis and rule/numerical baseline instead of an unsupported performance claim. |
| G6 18 Dec | Main results, figures and scope frozen. Remaining work is correction, packaging and defense. |

## Physical access routes

Route A is supervised student access for the pilot, calibration and confirmation sessions. Route B uses an Arche operator replaying the same approved commands and exporting logs plus a pose reference. Route B is acceptable only if configurations, timing, repeats and permissions remain traceable.

Historical logs can support identification if commands, configuration and time references are complete. Without an independent pose reference, report observable yaw/encoder/caster comparisons and limit trajectory-accuracy claims. Without any suitable real logs by 6 November, the project becomes a simulation study with a prepared physical protocol, subject to advisor acceptance. Physical validation remains uncompleted.

A delayed visit does not shift the official deadlines. Decline extensions to surfaces, hardware changes, extra models and deployment. If usable capacity still falls below 252 hours, reduce four maneuver families to two with the advisor, retaining repeated comparisons and the report. A necessary reduction of the scheduled learning experiment is also recorded with the advisor.

## Critical path

Platform access enables a usable pilot. The pilot enables calibration data. Calibration enables model/profile locking. The independent confirmation set enables evaluation and conclusions. Writing proceeds alongside each step. A learning model cannot remove any of these dependencies.
