Study design

Research questions

The two drive wheels set the motion in the ideal model. On the robot, the passive caster takes time to turn, especially during a reversal. I want to measure how far the path shifts and see whether a smoother command helps.

Does the caster model predict motion more accurately?

I’ll send the same commands to both models and check their predictions against an independent pose recording from the pilot. The Python and Simscape replays already show how the models respond in simulation.

Do smoother commands improve tracking?

Python already compares baseline and smoother profiles on synthetic surfaces. The robot study will use repeated confirmation runs to compare position error, yaw error and completion time.

Can telemetry predict yaw error?

I’ll check whether a short-horizon predictor beats persistence and a simple numerical baseline. I’ll split the data by whole runs once I have a suitable dataset. The ViNT check is part of the docking study.

The physical plan covers one robot configuration, two approved surfaces and four maneuver families. It requests 24 calibration runs and 48 confirmation runs. Three repetitions per condition are the starting target.
