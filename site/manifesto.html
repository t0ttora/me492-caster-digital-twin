How I work

Measure the robot separately

I use simulation to see how the model behaves under known inputs. To check its accuracy on the robot, I need an independent record of the robot’s motion under the same commands.

Keep the first run

When a test fails, I keep its trace beside the rerun. The first rounded-square run touched the wall. Both traces show what changed when I revised the corner radius and route.

Give each model a job

I use Python for controller changes I can replay quickly. Simscape measures loads and caster motion. Gazebo runs the ROS 2 nodes against a camera stream and lets me check how they react when a message is late or missing.

Leave confirmation runs untouched

I record the settings and inputs used for each test. Once the physical comparison is set, I’ll hold the confirmation runs back until evaluation.
