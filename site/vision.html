ME492 · Study design

Vision

Build a caster-aware digital twin whose predictions can be checked against the same commands and measured motion on an actual robot. Use the calibrated model to decide when a smoother command profile matters.

Research questions

RQ1 · Model fidelity
How much does explicit caster dynamics improve pose prediction? Compare the ideal and caster-aware models against command-matched independent pose measurements. Matched-torque simulation record ↗
RQ2 · Motion profiles
Can smoother timing reduce position and yaw error within the completion-time limit? Run the baseline and selected smoother profile on the same approved surfaces. Synthetic profile study ↗
RQ3 · Yaw prediction
Can a short-horizon predictor outperform persistence and a simple numerical baseline on held-out telemetry? Prediction work package ↗
