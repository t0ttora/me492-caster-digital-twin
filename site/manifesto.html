How I work

Measure the robot separately

I can give the simulator a known command and see how the model responds. To check its accuracy, I need to measure the real robot’s motion independently while giving it the same command.

Keep the first run

The first rounded-square run touched the wall. I kept it beside the rerun so I could see the effect of the new corner radius and route.

What I use each model for

I try controller changes in Python because I can replay them quickly. I look at loads and caster motion in Simscape. In Gazebo I can run the ROS 2 nodes with a camera stream and see what they do when a message is late or missing.

Leave confirmation runs untouched

I record the settings and inputs used for each test. When I set up the physical comparison, I’ll reserve the confirmation runs for evaluation.
