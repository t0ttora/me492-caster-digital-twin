# Visit Access Inventory

Questions to answer with evidence owners and dates

For every item, record Available, Restricted, Unavailable or Pending, along with the owner, delivery date and scope of permission. “Available” requires a file, tested interface or confirmed booking. Keep these distinctions in the meeting record.

| Item | Question and requested evidence |
| --- | --- |
| Actual platform | Which robot/hardware revision? Is differential drive the actual configuration? Request wheel/caster layout, mass/payload limits and identification photos if allowed. |
| CAD and mechanics | Can we receive CAD, simplified collision geometry, URDF/SDF, wheel radius/track, caster trail/position/material and mass/inertia data? What can be measured on site? |
| Software and commands | What OS/ROS version, drivers, APIs and controller interfaces exist? Is motion command replay permitted? Request interface documentation and a tested sample connection. |
| Telemetry | Which encoder, IMU, odometry, command, current and caster signals exist? At what rates and timestamps? Request a sample native log and channel description. |
| Independent reference | What external pose/video equipment exists? Can we use calibrated markers and a camera? What measurement accuracy and synchronization can we establish? |
| Robot access | Who supervises? Which two surfaces and area are permitted? Can Arche confirm the pilot, calibration and confirmation slots or offer operator-run capture? |
| Existing AI model | Does Arche have a relevant model? What task, inputs, outputs, weights, inference code and dataset access are available? Are training/adaptation and offline benchmarking allowed? |
| Compute and equipment | What student/lab/robot computer is available? What CPU, memory and GPU constraints apply? Who supplies permitted cameras/sensors and pays for consumables? |
| Data and ownership | What may leave the company? May logs/code enter external AI or cloud services? Who owns project code, derived datasets and trained weights? What may appear in the thesis/defense or public repository? |
| Publication and review | Is an NDA required? Who checks company information, within what agreed turnaround? Can we retain a reproducible academic package and a sanitized public subset? |

Read-only access, exported data and supervised tests are sufficient for the initial study. Ask for the smallest working access route. The announcement’s estimated expense of 0 TL is not confirmation that additional sensors, travel or compute are funded. [4]
